Summary
A Minecraft world type with snowy mountain passes, flowing rivers, fjords, rocky islands and desert oases.

Description
Choose European Wilderness when creating a world. Adjust terrain and biome proportions there, or use European Wilderness Explorer to pick a starting area.

Requires Windows x64, Java 21, Fabric Loader 0.18.1 or newer and Fabric API. The first launch downloads and verifies about 2.3 GB of terrain models. Mod Menu is optional.

MIT-licensed. Based on Alexander Goslin's Terrain Diffusion MC and ONNX models. Thanks to Joao for upstream DirectML support.
Source: https://github.com/xandergos/terrain-diffusion-mc
Models: https://huggingface.co/xandergos/terrain-diffusion-30m-onnx
