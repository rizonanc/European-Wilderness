# European Wilderness — восстановленный проект

Проект восстановлен из найденного terrain-diffusion-mc-2.2.0-windows+1.21.11.jar.
Это редактируемые исходники после декомпиляции. Старая история Git, комментарии,
тесты и планы разработки не сохранились.

Основа: https://github.com/xandergos/terrain-diffusion-mc (MIT), v2.2.0,
commit 23d3f50e5108882bb88a03c3ab048aa63633a02f.
Сохранены дополнительные европейские биомы, деревья, реки, горы,

## Сборка

Нужен JDK 21 и интернет для первой загрузки зависимостей.
В PowerShell в этой папке выполните:

    .\gradlew.bat build

Результат: build/libs/terrain-diffusion-mc-2.2.0-recovered-windows+1.21.11.jar
Minecraft 1.21.11, Fabric, Fabric API, Windows / DirectML.
Mod Menu необязателен, используется для доступа к настройкам.
ONNX-библиотека включается автоматически из libs/.
Манифест моделей сохранён из оригинала; первый запуск игры может скачивать модели.
