# 2.12.4 — сохранение мелководья в Voxy LOD

3 ноября 2026. Minecraft 1.21.11, Fabric, Voxy 0.2.16-beta.

## Подтверждённая причина потери данных

Пользователь воспроизводит пропадающую воду без шейдеров. Захват текущего
запуска подтверждает `NormalRenderPipeline`, а не Photon/Iris pipeline.
Вызов настоящего Mipper из запущенного Voxy с существующими ID палитры показал:
нижние четыре песчаных блока и верхние четыре блока воды превращаются в песок
(непрозрачность песка 15, воды 1). Вода исчезает из уменьшенных данных.

Дополнительно прочитаны девять существующих L1-секций перед игроком:
из 960 сплошных верхних участков воды 240 уже отсутствуют в сохранённом L2.
Примеры: (-72,62,-2172), (-68,62,-2172). Это локальная выборка, не статистика
всего мира и не доказательство единственной причины всех оптических стыков.
Исходные захваты: `recovery-evidence/water-composite-v2124/live-mip-proof.txt`
и `live-mip-scene.txt` в корне рабочей папки.

## Изменение мода

В четырёх местах уменьшения Voxy 16³-секции добавлен примитивный redirect.
После штатного выбора он сохраняет существующее водное значение верхнего угла,
если все четыре верхних значения содержат один и тот же водный block ID,
а штатный результат выбрал другой блок. Свет, биом и состояние берутся из
существующего верхнего значения. Смешанные берега, крыши и прочие материалы
остаются на штатном алгоритме. Проверка активна при наличии сессии TD.

Классификация ID принадлежит конкретному Mapper и кэшируется в нём. Общий
путь однородного рельефа обходится без создания объектов и обращения к палитре.
Код совместимости включается только для поддержанной версии Voxy на клиенте.
Сохранённые Minecraft-чанки и генерация рельефа/рек не меняются.

## Уже записанный кэш

Новая политика сама по себе не пересчитает старые LOD. Более того, стандартный
WorldUpdater прекращает обновление родителей, если базовая секция не изменилась.
Поэтому добавлен явный пересчёт существующего кэша:

```
/td-voxy water-rebuild 64
/td-voxy status
/td-voxy water-rebuild-stop
```

Радиус задаётся в чанках (1–256; без аргумента 16). Проверяется квадрат вокруг
игрока. Пересчёт идёт одним фоновым потоком, учитывает бюджет кадров, обходит
пустое небо по существующей иерархии и останавливается при смене мира/сессии.
Для прогресса держать мир открытым и окно активным.

Команда читает существующие базовые секции с водой, заново рассчитывает их
уменьшения и обновляет только существующие уровни 1–4. Базовый уровень 0 не
перезаписывается. Для сравнения строится и штатная старая иерархия. Атомарная
замена разрешена только при точном совпадении текущей ячейки со старым
результатом и только для перехода из непустого неводного блока в воду.
Параллельно изменённые ячейки, воздух и другие водные состояния сохраняются.
Смена песка на воду не меняет наличие дочерних секций:
оба значения не являются воздухом. Изменённые секции помечаются для обновления
мешей и записи стандартным механизмом Voxy. Мир, региональные файлы Minecraft
и исходный кэш не удаляются; Chunky и генерация новых чанков не запускаются.

## Проверки и оставшийся игровой шаг

* Настоящий pinned Mipper проверен на тонком слое во всех 16 вертикальных
  положениях через L1–L4. Прежний алгоритм теряет воду в 15 случаях; исправленный
  сохраняет её во всех 16. Проверены смешанный берег, крыша, чужие материалы,
  сохранение света/биома и быстрый путь однородных ячеек.
* Настоящие Mixins применены к pinned Mapper и WorldVoxilizedSectionMipper
  в изолированном процессе. Все четыре redirect применились, преобразованный
  mipper выполнен: L1–L4 сохраняют воду, базовые воксели побайтно неизменны;
  без сессии действует штатный выбор. Minecraft и GL для этого не запускались.
* Адресация выборочной миграции сопоставлена с настоящим writer Voxy на
  уровнях 1–4, включая отрицательные координаты. Посторонние и параллельно
  изменённые значения сохраняются, повторный вызов идемпотентен. Восстановление
  старой иерархии совпадает со штатным mipper побайтно. Пересчёт не вызывает
  приватный writer Voxy и не обновляет базовые данные.

Полный видимый результат и запуск команды в игре требуют установки нового JAR.
Визуальный баг пока не объявлен полностью исправленным. Первый контроль — тот
же океан без шейдеров после завершения `water-rebuild`. В этой версии Photon
не менялся. Установленные моды, настройки, сохранения и LOD-кэш автоматически
не изменялись при подготовке сборки.
