# История: прямой мост Terrain Diffusion → Voxy, 2.5.0 preview

Целевая связка: Minecraft 1.21.11 / Fabric, **Voxy 0.2.16-beta** и совместимый
с ним Sodium. Voxy устанавливается отдельно. SeedGen для этого моста не нужен.
Это первая расчётная интеграция; игровой прогон с Voxy/GPU ещё не выполнен.

## Что реализовано

Мост передаёт свои воксельные секции через публичные методы Voxy. Новые
Minecraft Chunk/ProtoChunk/ChunkSection не создаются; features, освещение,
сущности и обычная генерация чанков не запускаются ради LOD.
Voxy выполняет собственное уменьшение детализации, обновление и сохранение.

Источник — существующие исходные terrain tiles и окончательные планы воды.
Высоты учитывают уже принятые русла, озёра, уступы водопадов и береговой рельеф.
Есть вода моря и рек, биомы, упрощённая поверхность и вертикальная завеса
водопада. Под землёй — сплошная порода. Слой почвы, материалы, свет, отсутствие
полублоков и растительности — приближение для LOD, а не полный результат
генерации. Деревья, структуры, пещеры, небольшие береговые детали и изменения
игрока появляются через обычный импорт реальных чанков самим Voxy.

По умолчанию включён **только экспорт уже рассчитанных планов**. Это позволяет
показывать также территорию, рельеф/вода которой подготовлены наперёд, даже
если Minecraft-чанков там ещё нет. Сам этот режим не запускает inference.
Для дополнительной подготовки более далёкой области есть отдельная команда.

## Как проверить

1. Заменить старый JAR Terrain Diffusion на 2.5.0; установить Voxy 0.2.16-beta
   с его зависимостями. Отключить **Voxy SeedGen** и другие фоновые генераторы
   LOD, чтобы несколько независимых алгоритмов не писали одну область.
   При обнаружении SeedGen этот мост отказывается запускаться.
2. Открыть одиночный мир Terrain Diffusion с автоматической водой (2.4.0+).
   Поддерживается также хост LAN. Для удалённого сервера, seed/нейрорельефа
   которого нет на клиенте, этот вариант моста не работает.
3. Включить Voxy и обычное получение данных мира в его настройках.
   Проверить `/td-voxy status`.
4. Для подготовки LOD дальше уже рассчитанной территории:

       /td-voxy start 1024
       /td-voxy status

   Радиус задаётся **в блоках**, допустимо 64..2048. Начинать разумно с 1024.
   Команда дополнительно разрешает небольшие фоновые шаги Terrain Diffusion.
   Работает только при хорошем среднем времени тика сервера, отсутствии
   срочных запросов и ручной подготовки; начатый GPU-вызов не прерывается.
   Нейросетевой рельеф может готовиться существенно дольше seed/noise-генерации;
   скорости SeedGen и радиусы в десятки тысяч блоков здесь не обещаются.
5. `/td-voxy stop` останавливает мост и новую работу; принятые данные остаются.
   Уже начатый конечный этап заканчивается. Старт после stop снова разрешён.

Текущий мир 2.4.0/2.4.1 можно продолжать: география и форматы исходного рельефа/
воды не изменены. Для чистого сравнения LOD полезен отдельный тестовый мир:
уже существующие записи Voxy мост не перерисовывает. Ошибочные старые LOD от
другого генератора автоматически не очищаются. Файлы пользователя не удаляются.

## Ограничения записи и потоков

- Один worker, очередь в одну задачу, радиус до 2048, ограниченная память
  пройденных мест (16384) и до четырёх снимков готовой воды.
- Сканирование использует заранее упорядоченные смещения; движение игрока не
  сортирует заново всю область каждый клиентский тик.
- Секция Voxy 32³ проверяется через acquireIfExists. Занятая секция пропускается;
  пустая заполняется восемью дочерними voxel sections 16³ и уменьшается штатным
  WorldVoxilizedSectionMipper. Внутри одной 32³-секции отмена не выполняется.
- Никакие поля внутренних массивов WorldSection не меняются напрямую.
  Запись выполняет публичный WorldUpdater.insertUpdate, с обычными callbacks.
- Закрепление engine через acquireRef происходит на клиентском потоке только
  после готовности данных. Во время inference и ожидания клиентского потока
  engine не удерживается. releaseRef выполняется после конечной записи.
- Переход мира, деактивация сессии или отключение Voxy запрещают следующий
  этап. Если реальный чанк пришёл одновременно с записью, загрузка отменяет
  дальнейший экспорт столбца, а доступные реальные чанки повторно передаются
  штатному ingest Voxy. Это даёт приоритет настоящему содержимому мира.
- Проверка пустоты и запись не являются общей атомарной операцией с любым
  посторонним importer. Поэтому одновременные сторонние генераторы/import
  во время теста не поддерживаются. Частично изученная существующая секция
  32³ сохраняется целиком, даже если в её других частях ещё нет LOD.
- Яркость LOD приближена к дневному skylight; полное распространение света и
  игровая жидкостная физика не моделируются.

В `config/terrain-diffusion-mc.properties`:

    compat.voxy.enabled=true
    compat.voxy.radius_blocks=1024

Отключение через false применяется после перезапуска. Наличие Voxy необязательно:
без него Terrain Diffusion продолжает работать, `/td-voxy status` объясняет
отсутствие интеграции. Другие версии Voxy намеренно отклоняются до проверки API.

- [Описание и лицензия SeedGen](https://modrinth.com/mod/voxy-seedgen)

Публичные сигнатуры сверены с официальным JAR Modrinth H3w2nVdU. В его
fabric.mod.json указан тот же commit 59b62bee821518e06612e1d5c2c58c487bda761d.
Не использовалась декомпиляция SeedGen/REA. Наши алгоритмы sampling/очереди/
публикации написаны отдельно; mip, кодирование и запись вызывает установленный
Voxy. Классы, исходники и JAR Voxy не включаются в сборку или архив исходников.
Референсы остаются только локально вне recovered-project. Это описание способа
интеграции, не универсальный правовой вывод о допустимости любого реверса.

Отражение используется только для публичных интерфейсов и фиксированной версии,
без setAccessible и доступа к private-полям. Так отдельная зависимость с новой
версией Loom не заставляет обновлять сборочный стек всего восстановленного мода.

115 JUnit-тестов прошли без ошибок/пропусков в локальном окружении. Новые
проверки охватывают read-only экспорт без inference, отделённость снимков,
отказ при смене сессии, профиль океана/реки/снега/песка, пропуск занятых секций,
повторный экспорт, отмену между секциями, неактивный engine, отрицательные
координаты, лимит памяти, смену направления, запрет другой версии и SeedGen.
Тестовый sink не является игровым Voxy. Публичный ABI и упаковка проверены
отдельно; реальный GPU/mip/рендер/конкурентный ingest требуют игрового осмотра.
