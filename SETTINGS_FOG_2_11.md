# Настройки и видимость — 2.11.0, 1 ноября 2026

В Mod Menu доступны все 20 параметров из `terrain-diffusion-mc.properties`:
модели, карта, генерация, скорость, Voxy и LOD. Список полей и редактор
используют общий каталог; тест сверяет его со всеми ключами bundled config.
Есть подсказки, проверка диапазонов, сохранение комментариев и неизвестных
параметров. Вкладки размещены в два ряда; на странице не больше четырёх полей.
Поля TD применяются после сохранения и перезапуска Minecraft.

Добавлен `compat.voxy.radius_mode=auto|manual`. В режиме auto сохраняется
дальность Voxy (или WorldGen без coarse), в manual используется
`compat.voxy.radius_blocks`. 32768 блоков = 2048 чанков **радиуса**.
Сам Voxy тоже должен иметь достаточную дальность отрисовки. Подробная зона
`compat.voxy.detail_radius_blocks` управляет точными реками/лесом, не всем горизонтом.

## Что показала проверка установленной 2.10.0

В профиле пользователя были `enabled=false` и `enable_rendering=false` у Voxy,
`section_render_distance=64`, Minecraft `renderDistance:32`, Iris с Photon 1.4.
32 обычных чанка — **512 блоков**, а не 512 чанков. Выключенная отрисовка Voxy
не показывает его дальний горизонт, даже при настроенном радиусе 2048 чанков.

Счётчики до изменения: coarse patches=8, rendered=49385, notify=16420,
errors=0, dropped=0. Это подтверждает предыдущую работу coarse-пути,
но `rendered` включает соседние/повторные чтения, не уникальные чанки.
GPU cache: три резидентных сессии, три создания, 1161 повторное использование,
без memory fallback. Во время чтения экспорт ожидал включённого Voxy.

## Вкладка «Видимость»

Показывает обычную дальность в чанках **и блоках**, фактическое включение
отрисовки Voxy, его дальность и активный шейдер.

- «Настройки Voxy» открывают его родной экран: включение мода/отрисовки,
  дальность, туман, потоки и остальные параметры Voxy.
- «Настройки шейдера» открывают Iris.
- «Photon: слабый туман» явно применяет `OVERWORLD_FOG_INTENSITY=0.10` и
  `BORDER_FOG=false`, затем вызывает обычную перезагрузку Iris.
- «Photon: обычный туман» задаёт `1.00` и `true`. Это стандартные значения,
  а не восстановление произвольных прежних пользовательских значений.

Две кнопки Photon активны только для выбранного Photon. Проверяется наличие
обоих параметров в текущем shader option set. Остальные параметры сохраняются:
в публичную очередь Iris добавляются только две выбранные опции. Не используется
API, сбрасывающее остальные shader options к defaults. ZIP шейдера не изменяется;
Iris сам сохраняет свой файл опций. Пересборка шейдера по нажатию может занять время.
Вода и отдельная интенсивность тумана Нижнего мира этим preset не меняются.

Эти кнопки применяют изменения сразу; обычное сохранение настроек TD не
трогает шейдер и не включает Voxy автоматически. Без включённой отрисовки Voxy
ослабление тумана лишь лучше покажет границу обычной прорисовки Minecraft.

## Выключение и повторное включение Voxy

Доступность моста теперь учитывает `enabled` и `enableRendering`, вместе
с прежней проверкой ingest. При недоступной отрисовке старый контекст завершается,
его очереди и coarse producer останавливаются. При возвращении создаётся новый
контекст с актуальным WorldEngine. Это также устраняет привязку coarse к старому
engine после выключения/включения Voxy. Точные файлы рельефа и водные планы сохраняются.

## Проверки

242 теста без ошибок и пропусков. Новые тесты проверяют полноту каталога,
defaults для старых config-файлов, диапазоны/переключатели, round-trip всех новых
полей, CRLF/комментарии/неизвестные ключи, отказ записи неверного config,
русские и английские подписи/подсказки и сохранение остальных shader options.
Повторно проверено применение трёх coarse mixin к Voxy из готового remapped JAR.

Новый экран и применение Photon preset ещё не проверены в игровом/GL-прогоне.
Реальный профиль, шейдерный ZIP и сохранение пользователя при разработке не менялись.
После установки проверить: Mod Menu → Terrain Diffusion → Видимость, включить
нужную отрисовку Voxy и нажать выбранный preset Photon. Затем проверить дальний
горизонт в активном окне игры и `/td-voxy status`.
