# 2.8.1 — ранняя очистка старых верхних секций LOD

31 октября 2026. Fabric 1.21.11 / Java 21. Связка Voxy 0.2.16-beta,
VoxyWorldGen 2.2.4 сохранена.

По скриншоту автора 2.8 проблема стенки на границе дальнего рельефа осталась.
Проверка установленных модов подтвердила 2.8.0. Read-only проверка файлов
«Новый мир (20)» сравнила отдельные колонки настоящих полных чанков с
замороженным водным планом. В большинстве точек высоты совпали точно,
в остальных обычно различались на несколько блоков. Это не подтверждает
универсальную ошибку смещения всей дальней поверхности на десятки блоков.
Файлы читались во время игры, без атомарного снимка, поэтому проверка
не заменяет наблюдение текущего состояния Voxy.

Найден конкретный дефект очереди: очистка существовавших секций выше новой
поверхности выполнялась только после достройки подземной толщи. Колонки,
ожидающие соседнего водного ядра для леса, могли задерживать эту очистку ещё
дольше. Теперь первый проход записывает новую поверхностную полосу и очищает
старые секции над ней, затем оставляет компактную задачу леса/подземной достройки.
Пустое небо не заполняется новыми секциями. Маска реальных чанков сохранена.

Это исправление воспроизводимого дефекта, а не подтверждение, что именно он
объясняет весь скриншот. Доступ к игре через mcpfabric сейчас отклонён из-за
несовпадения токена. Токены в исходники и отчёты не добавлялись. Полное исчезновение
стенки и отсутствие постоянных пробелов необходимо подтвердить в игре.

`/td-voxy status` дополнен числом незавершённых колонок и колонок, ожидающих лес.
Для следующей проверки полезны этот статус и наблюдение одной границы при
неподвижном игроке. Удаление кеша или чанков не выполнялось и не требуется
для применения нового порядка: неподтверждённый настоящими чанками LOD
пересматривается при новом сеансе.

Новая регрессия моделирует высокие старые секции, остановку по кадровому бюджету,
неподготовленный лес и продолжение подземной достройки. Полная сборка: 191 тест.
Водный алгоритм остаётся 4; правила копии мира и отката из SURFACE_STREAM_2_8.md
сохраняются. Реки, деревья и формат файлов в этой правке не менялись.
